Issue EXIF rotation feature fix This fix will disable EXIF rotation, a feature activated by the model update mentioned in the November 11, 2020 release note. This feature affects the DOCUMENT_TEXT_DETECTION and TEXT_DETECTION features. EXIF rotation will be turned down on March 22, 2021 . If your usage relies on this specific behavior, please file a feature request to us.
